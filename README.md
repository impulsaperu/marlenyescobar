# Marleny Escobar Hair Studio — Web Oficial

Sitio web de marca personal para **Marleny Escobar**, especialista en transformación capilar en Lima, Perú.

**URL:** [marlenyescobar.com](https://marlenyescobar.com)  
**Repo:** [github.com/impulsaperu/marlenyescobar](https://github.com/impulsaperu/marlenyescobar)

## Objetivo

Crear una presencia digital premium donde las clientas puedan:
- Conocer a Marleny Escobar como especialista.
- Ver servicios y resultados.
- Descubrir productos profesionales recomendados.
- Agendar una cita directamente por WhatsApp.
